# Antigravity Landing Page (Next.js)

> **개발의 중력을 거스르는 완전 자율형 AI 코딩 에이전트, Antigravity**  
> Google DeepMind의 차세대 자율 소프트웨어 엔지니어링 에이전트 Antigravity를 소개하는 인터랙티브 원페이지 랜딩 페이지입니다.

---

## 🚀 주요 기능 및 구성

- **Zero-Gravity Hero**: 심우주 다크 모드, 네온 글래스모피즘, 발광 그라디언트 및 부유 애니메이션
- **Interactive Agent Cockpit**: 3가지 실제 엔지니어링 시나리오(신규 웹 앱 빌드, 버그 자가치유, 브라우저 시각 검증)를 실시간 터미널 스트림으로 체험
- **4대 핵심 역량**:
  - ⚡ High-Agency Planning (심층 다단계 계획 수립)
  - 💻 Full OS & Shell Control (터미널 및 프로세스 완전 제어)
  - 🌐 Browser Subagent (브라우저 직접 조작 및 DOM/스크린샷 검증)
  - 🧠 Permanent Knowledge (프로젝트 지식 저장소 & 커스텀 스킬)
- **비교 분석 매트릭스**: 기존 AI 자동완성 도구(Copilot 등) vs Antigravity 완전 자율 실행 비교
- **검증된 지표**: SWE-bench Verified 92.4%, 개발 속도 10x 가속
- **원클릭 CLI 복사 & 인터랙티브 FAQ 아코디언**

---

## 🛠️ 기술 스택

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS Modules (디자인 시스템 기반 다크 글래스모피즘)
- **Fonts**: Google Fonts (Outfit, JetBrains Mono)

---

## 💻 로컬 실행 방법

```bash
# 종속성 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속하여 확인합니다.
